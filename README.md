# 🛒 Amazon Frontend Clone

Welcome to the **Amazon Frontend Project** — a fully responsive, interactive e-commerce web app built using **HTML, CSS**, and **JavaScript**. This project is part of my journey to master modern frontend development and JavaScript skills through hands-on learning and real-world simulation.

---

## 📚 Learning Goals and Covered Topics

This project incorporates concepts and techniques what i learnt and understand for frontend development:

### 1. JavaScript Basics
- Syntax, structure, `console.log`, and basic program flow.

### 2. Numbers and Math
- Arithmetic operations, `Math` object, random generation.

### 3. Strings
- Manipulation, interpolation, template literals.

### 4. HTML & CSS Review
- HTML5 semantic elements, CSS styling, layouts, and media queries.

### 5. Variables
- `let`, `const`, scope, hoisting.

### 6. Booleans and If-Statements
- Comparison operators, logical operators, control flow.

### 7. Functions
- Function declarations, expressions, arrow functions, parameters, and return values.

### 8. Objects
- Object literals, property access, nested objects, `this` keyword.

### 9. Document Object Model (DOM)
- `querySelector`, `addEventListener`, DOM traversal, manipulating styles and content.

### 10. HTML, CSS, and JavaScript Integration
- Structuring interactive pages combining all three technologies.

### 11. Arrays and Loops
- Iteration using `for`, `while`, `forEach`, and array methods (`map`, `filter`, etc).

### 11.2 Arrays and Loops (Advanced)
- Nested loops, performance considerations, higher-order functions.

### 12. Advanced Functions
- Closures, callbacks, function scope, currying, and recursion.

### 13. Start of Amazon Project + Intro to Git
- Cloning, branching, commits, GitHub workflow.

### 14. Modules
- `import`/`export`, organizing code into reusable parts.

### 15. External Libraries
- Using third-party JS libraries (e.g. Axios, Lodash, Toastify).

### 16. Testing
- Writing tests using JavaScript.

#### 16.1 Testing Frameworks
- Introduction to tools like Jest, Mocha, and understanding unit vs integration tests.

### 17. Object-Oriented Programming (OOP)
- Classes, constructors, methods.

#### 17.1 Inheritance
- Prototypes, ES6 class inheritance, extending functionality.

### 18. Asynchronous JavaScript
- `fetch()`, promises, async/await, callbacks.

---

## 💡 Features of the Project

- Responsive UI similar to Amazon
- Product display with images, descriptions, and prices
- Add-to-cart functionality
- Cart item quantity updates
- Local storage usage
- Modular, reusable JavaScript
- Clean folder structure with separation of concerns
